Getting help

Report a problem or ask a question: open an issue at github.com/edbouverie/moongate-site/issues. Include your macOS version, the shard you were connecting to, and what you expected to happen.

Abuse by another player on a shard should also be reported to that shard's operators; in the app you can block a player under Settings → Interface → Chat → Ignored players (or type -ignore <name> in chat) and switch on Hide public chat.

Frequently asked

Where do the game files come from? Moongate ships no game content. On the login page, Download Files fetches the official client files from the publisher's patch servers, or Locate client files points the app at a folder you already have.

Which servers can I play on? Any Ultima Online–compatible server: community shards built on ServUO or RunUO, and the official servers if you have an account there and their terms allow the client you use.

Where are my settings? In the app's sandbox container. Profiles can be synced between Macs through iCloud (Settings → Profiles → Sync).

Scripts? Moongate runs Python automation scripts through the Legion API. Scripts run only when you start them; the public script browser lists community scripts from GitHub.
